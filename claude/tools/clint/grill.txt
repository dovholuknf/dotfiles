# clint grill scenarios. Each [reply id] block is one scenario:
#   ask:   the setup: who you are, who is asking or what you were asked to write, and where
#   true:  the facts the answer has to carry
#   mark:  a phrase this scenario tests, one per line. If the user's reply still has it, they kept it.
#   then the reply an LLM wrote
# The user writes exactly how they would reply, or types = to send the LLM reply unchanged.
#
# How the set is built, so each answer teaches something new:
# - Anyone can answer. The scenarios happen around the Thrombonifier, a made-up app that turns recipes into shopping
#   lists, and around everyday work: chat with a coworker, email from a customer, a report from an AI assistant. The
#   setup carries everything the reader needs, so nobody has to know a field to write a reply.
# - One or two habits per reply, the rest written plainly. If a reply carries six habits, a rewrite can't show which
#   one bothered the reader.
# - Contrasts. Several habits appear twice, once where they grate and once where they are fine, in scenarios far
#   apart so the first doesn't prime the second: a label vs a plain "honestly", asking before deleting vs offering
#   the obvious next step, "genuine" as a fact vs as an intensifier, "ensure" as an instruction vs a claim, Critical
#   as a rating vs as emphasis.
# - Controls. Some replies are already plain. Typing = on those shows what the reader keeps, and rewriting them anyway
#   shows a habit no rule names yet.
# - Mixed registers: chat, reports, change logs, help pages, notes in instructions, bug reports, release notes,
#   customer email, a blog opening. Mixed lengths, with no two long replies in a row.
# - The first scenario is a short control, so the reader learns = before the work starts.
# Lines starting with # are comments before the first block. Edit freely, ids only need to be unique.
